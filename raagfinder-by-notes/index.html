    raagfinder-by-notes

    Find the raags built out of a given set of notes. The raag information comes from tanarang.com, bundled in the libmogra package — this page is the browser version of mogra search SRGMPDn.
    Instructions for use:
    • Enter a subset of S r R g G m M P d D n N
    • Case sensitive -- m = shuddha, M = teevra.
    • Order and repeats don't matter, and anything that isn't a note is ignored.
    • The match is on the exact set of notes, so a 7-note raag won't show up for a 6-note query.
